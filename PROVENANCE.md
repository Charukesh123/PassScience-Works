# Sample data provenance (CC0 / public domain dedication, self-created)

| File | What it is | Units | Origin |
|---|---|---|---|
| `rod_cylinder.stl` | ASCII STL of a 1 m long, 24-sided prism approximating the rod of Task C (r = 5.6419 mm so A = 1e-4 m^2), 96 triangles | metres | Generated by `tools/make_sample_data.py` (original work) |
| `ansys_synthetic_nodal_temperature.csv` | **SYNTHETIC. Not an actual ANSYS export.** 189 nodes = 21 axial stations x (1 centre + 8 ring) nodes, temperature from the analytic rod solution T(x) = 100 - 80x + 500x(1-x) | x_m,y_m,z_m in metres; temperature_C in degrees Celsius | Same script |

CSV schema: `node_id,x_m,y_m,z_m,temperature_C` - header exactly as written, comma separated, one node per row,
integer unique `node_id`, finite decimal numbers. A real ANSYS export would be produced by e.g. listing nodal
temperature with coordinates and re-saving as CSV with these column names; this repo contains no such real export.
No registration between the two files is assumed or performed.
