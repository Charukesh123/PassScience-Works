# Dependencies and versions
Runtime/third-party libraries: **none** (C++17 standard library, Winsock2/Win32 on Windows, POSIX sockets elsewhere; browser built-ins for the UI: Canvas 2D, fetch).
Toolchain used for the evidence in results/: GCC 13.3.0 (Ubuntu 24.04), Python 3.12 + matplotlib 3.10.8 (plotting helper only), CMake file written for >= 3.20 (not executed on the authoring machine).
